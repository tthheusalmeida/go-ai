# Go-AI

> Um serviço de ferramentas de IA em Go.

## Configurando a máquina

Dê permissão de execução ao script:

```bash
chmod +x ./scripts/setup.sh
```

Execute o setup:

```bash
sudo ./scripts/setup.sh
```

Em caso de sucesso, aparecerá a mensagem:

